# Planned learning-outcome evidence

Official unit: https://www.sydney.edu.au/units/ENGG2112

| Outcome | Implemented evidence | Later evidence still required |
|---|---|---|
| LO1: justify ML engineering solutions | Research purpose, architecture and measured XGBoost/baseline comparison | Pricing justification and final-test evaluation |
| LO2: independently evaluate information | Provenance chain, source notes, licence and DST uncertainty | Critical evaluation of research and model results |
| LO3: project management/teamwork | Staged log and planned roles | Actual team contributions and reviews |
| LO4: medium-scale data analysis | Real CSV processing, features, six fitted candidates and validation diagnostics | Extended robustness evaluation |
| LO5: ML and engineering methods | Temporal validation, leakage tests, persistence and trained XGBoost models | Constrained simulation and final test |
| LO6: store/process/interpret data | Parquet, hashes, model persistence, independent refits and day forecasts | Integrated application |
| LO7: broader implications | Sampling and demographic limitations | Economic, regulatory, equity and deployment analysis |

These are evidence locations, not a declaration that every outcome is satisfied.
